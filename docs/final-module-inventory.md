# Final implemented module inventory

All API groups use `/api/v1` unless stated otherwise. Protected domain groups require an active first-party Sanctum session; Admin groups also require ADMIN. Seller means relevant Shop ownership. Policies and locked service validation remain authoritative.

| Module / purpose | Actors | Important implemented rules | Main API groups | Notable controls |
| --- | --- | --- | --- | --- |
| Authentication / recovery | Guest, User, Admin | Register assigns USER/ACTIVE; active login; session rotation; generic forgot response; broker expiry/single use | `/auth/register`, `/auth/login`, `/auth/logout`, `/auth/me`, `/auth/forgot-password`, `/auth/reset-password`; `/sanctum/csrf-cookie` outside API prefix | Validated fields, password hashing, stateful CSRF, login/register/reset limits; no API reset token |
| Profile / Address | Current User | Name/phone editing; owned CRUD/default selection; default changes serialized on account | `/profile`, `/addresses`, `/addresses/{id}/default` | AddressPolicy/owned queries, locked defaults, no role/status editing |
| Shop | Owner, Admin; Guest reads | One Shop/owner; PENDING/ACTIVE/SUSPENDED/REJECTED moderation; active owner required for public selling | `/shops`, `/seller/shop`, `/seller/shop/submit`, `/admin/shops` | ShopPolicy, expected-status moderation, audit, archived/inactive visibility |
| Category | Guest reads, Admin writes | ACTIVE ancestors; acyclic tree, maximum three levels; referenced/parent categories cannot be deleted arbitrarily | `/categories`, `/admin/categories` | Admin/Policy, tree lock, FK restrictions/validation |
| Product / Images | Guest reads, owning Seller, Admin | DRAFT → submit → PENDING → ACTIVE; explicit hide/revise/withdraw; up to eight images, one normalized primary | `/products`, `/seller/products` and action/image subpaths; `/admin/products` | Product/Image Policies, parent scoping, visibility, safe re-encoding, upload limits, audit |
| Cart | Buyer | Quantity 1–99; no own-Shop purchase; availability rechecked; auction claims block fixed purchase | `/cart`, `/cart/items` | Owned items, locked writes, no client price authority |
| Checkout | Buyer | Owned address; live server prices, stock reservation, Shop grouping; UUID Idempotency-Key + payload hash | `POST /checkout` | Transactions/ordered locks, BCMath, tamper rejection, idempotency conflicts |
| Orders | Buyer, owning Seller; Admin reads | Item/address snapshots; fulfillment per ShopOrder; guarded cancellation/one-time stock restoration | `/orders`, `/orders/{id}/shop-orders/{id}/cancel`, `/seller/orders`, `/admin/orders` | Order/ShopOrder Policies, expected_status; no Admin fulfillment |
| COD / ZaloPay | Buyer, Seller for COD; gateway, Scheduler | COD collection confirmed at completion; online attempts pending until verified; retry/query and late-money reconciliation | `/orders/{id}/payments`, `/orders/{id}/payments/zalopay`, `/orders/{id}/payments/zalopay/query`, `/payments/zalopay/callback` | Rate limits, MAC/reference/amount checks, unique attempts/transactions, locked confirmation; return URL is not payment proof |
| Reviews | Eligible Buyer, Admin; Guest reads | Completed matching purchase, one review/order item, no own-Shop review; author edits; publish/hide | `/products/{slug}/reviews`, `/products/{slug}/review-eligibility`, `/order-items/{id}/review`, `/reviews/{id}`, `/admin/reviews` | Policy, locked relationship checks, published summary predicate, rating 1–5 |
| Seller Dashboard | Shop owner | Existing counts/revenue/recent Orders; date/group controls | `/seller/dashboard`, `/seller/dashboard/revenue` | Current-Shop scoping, validated report range |
| Seller Inventory & Action Center (D4 ✅) | Shop owner | Stock list with LOW_STOCK/OUT_OF_STOCK states from a configurable threshold; quick stock update reuses the product update endpoint with `expected_updated_at`; action counts for stock, moderation, orders needing action and live/ending auctions | `/seller/inventory`, `/seller/action-center`, `PATCH /seller/products/{id}`, `/seller/orders?action_required=1`, `/seller/auctions?live_now=1` | Current-Shop scoping, optimistic concurrency, auction-claim lock, aggregate queries that do not grow per product |
| Admin Action Center (D5 ✅) | ADMIN | Aggregate counts of pending shops/products, open reports by status and target, flagged users, payments awaiting reconciliation, auctions awaiting checkout or overdue; reconciliation decision `REFUNDED_OUTSIDE` / `KEEP_PAID` with note; Admin cancellation of SCHEDULED/LIVE auctions with bids; running auction must be cancelled before hiding its product; shop suspension cancels its running auctions | `/admin/action-center`, `/admin/payments`, `/admin/payments/{id}/reconciliation`, `/admin/auctions`, `/admin/auctions/{id}/cancel`, `/admin/users?flagged=1` | EnsureAdmin + Policies (no self-dealing on own auction/order/report target), row locks, `expected_status`, mandatory reason/note, audit, after-commit events, constant query count |
| Vouchers (D6 ✅) | USER, shop owner, ADMIN | Shop and platform codes at fixed-price checkout (also with buy now), price preview, discount split per shop order, snapshot of code and discount on the order, release on cancellation, voucher management screens | `/checkout/preview`, `/checkout`, `/seller/vouchers`, `/admin/vouchers` | BCMath, whole-dong rounding down, vouchers locked last by ascending id inside the checkout and cancellation transactions, codes in the idempotency hash, policy + IDOR tests, real-MySQL race test; details in [D6 verification](extension-d6-vouchers-verification.md) |
| Recommendations (D7 ✅) | Guest, USER | "Gợi ý cho bạn" on the home page and "Sản phẩm tương tự" on product detail; hybrid score of category/shop affinity, recent search keywords, Bayesian rating, popularity and recency; cold start uses popularity + recency only; view log deduplicated per 30 minutes, search log, both for signed-in users only | `/recommendations`, `/products/{slug}/similar` | Public-visible products only, own shop excluded, no randomness, id tie-break, constant query count, per-user cache key, weights in `config/recommendations.php`; formula in [recommendation-scoring.md](recommendation-scoring.md) |
| Admin | ADMIN | User/status, Shop/Product/Review moderation, Categories, dashboard, read-only Orders; self-lock/conflict protections | `/admin/dashboard`, `/admin/users`, `/admin/shops`, `/admin/products`, `/admin/categories`, `/admin/orders`, `/admin/reviews` | EnsureAdmin + Policies, expected-status/actions, audit; UI guards supplementary |
| Messaging | Buyer/Seller participants | Optional Product context; reuse context; no self-chat; text ≤1,000 chars; history/read cursor | `/conversations`, `/conversations/{id}/messages`, `/conversations/{id}/read` | Participant Policy, limit/trim/escaped text; unavailable context omitted, history retained |
| Auction | Guest discovers, User bids, Seller manages; Scheduler | LIVE/time-window; first ≥ start, later ≥ current + increment; safe cancel before bids/end; idempotent winner finalization | `/auctions`, `/auctions/{id}/bids`, `/auctions/{id}/checkout`, `/seller/auctions` | Ownership, lock/recheck, decimals, active-product uniqueness, server_time, winner-only one-Order checkout |
| Notifications | Owner; lifecycle service generates | OUTBID/WON/ENDED/CANCELLED/EXPIRING/ORDER_CREATED; persist first, recipient/event dedup, read/read-all | `/notifications`, `/notifications/unread-count`, `/notifications/{uuid}/read`, `/notifications/read-all` | Owner-scoped UUIDs, safe routes/payload, private channel; no general all-Order event engine |
| Product Video | Seller uploads, Guest views | MP4/WebM; default 3/product, 50 MiB/file; READY visibility, primary/order/hide/delete; no transcoding | `/seller/products/{id}/videos`, `/products/{slug}/videos`, `/videos` | Parent ownership, MIME/extension/container checks, UUID paths, ready-primary uniqueness |
| Theater Mode | Guest/User | Homepage video feed opens responsive Theater, native controls, Product/Arena CTA, keyboard close | Existing `/videos` and `/videos/{id}` reads; no independent Theater backend | Safe context, focus/cleanup, unavailable content excluded; codec limits |
| Realtime Video Comments | Guest reads, User posts, author/owning Seller/Admin hides | Text ≤500 chars; PUBLISHED/HIDDEN; cursor history, committed create/hide events | `/videos/{id}/comments`, `PATCH /video-comments/{id}` | Policy, locked visibility recheck, rate limit, escaped text; safe public payload |

Fulfillment is PENDING → CONFIRMED → PROCESSING → SHIPPING → COMPLETED with permitted cancellation branches; payment is separate. Shipping fees/discounts currently default to zero; schema fields do not imply coupon/shipping-pricing features. VNPAY/REFUNDED and video PROCESSING/FAILED values do not imply delivered gateway/refund/transcoding workflows.
